# BLOCKYCLAW

ブラウザですぐ遊べるゲーム。インストール不要。

| ゲーム | 内容 |
|---|---|
| 一尾入魂 SABAKI | 魚さばき。鱗取り、頭落とし、三枚おろし、刺身、盛り付け |
| HADAL BLUE | 深海ダイブ（WebGPU、PC の Chrome / Edge 推奨） |
| VOID SHIFT | FPS（ボット戦） |
| 毒うさぎ命名ゲーム | 毒うさぎに名前をつける。名前の音に合わせて踊る |
| 物ボケ人形 | 場面と道具をひいて、ぐにゃぐにゃ人形で物ボケ。リンクで友達にツッコんでもらう |
| ふちまで注げ | 目隠しで、注ぐ音だけを頼りにグラスのふちぎりぎりまで注ぐ。結果を X でシェア |
| 合格発表 早押し | 掲示板から自分の受験番号を最速でさがす。当たるたびにそっくりな番号が増える |

魚・料理の写真は AI で作ったもので、実在の個体や料理ではありません。
HADAL BLUE は Abyssal Garden（Noniv、MIT）をもとにしています。
