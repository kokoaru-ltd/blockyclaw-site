# イキスギドラレコ

GitHub Pagesでそのまま動く、接触せず60秒の完走を目指す3Dサバイバル・ドライブ。ビルド不要。`index.html`をHTTP経由で開く（ES modulesのため`file://`では起動しない）。

- 開始画面は「運転する」と「操作・音声」。操作説明・消音・14セリフの試聴は設定ダイアログに集約。
- ↑ / W：アクセル、↓ / S：ブレーキ、← → / A D：ハンドル
- Space：クラクションと一言、P / Escape：一時停止、R：最初から
- スマホは画面下のボタン。開始操作で音声が有効になり、「音 OFF」で消音。14種類の同梱MP3を場面に応じて再生し、直近2種類の連続使用を避ける。
- 制限速度は10秒ごとに60、100、140、180、220、260 km/hへ上昇。赤信号の通過にペナルティはない。
- 通行人・車両・連続ガードレールへ接触した時点で即アウト。運転・得点・生存時間を固定し、11剛体・10関節のラグドール事故映像を約2.65秒だけ再生してGAME OVER。再開して運転を続けることはできない。60秒を接触せず走れば「完走」。流血表現なし。
- 道路は弧長に沿う左右カーブと工事区間の幅員減少を持つ。路面・車線・ガードレール・街区・車・通行人・カメラを同じ `roadPoint` 座標で配置。操舵には慣性と速度・曲率に応じた外向きの流れがあり、停止中の横滑りはない。車幅と向きを含む連続区間の衝突検出で、路肩のすり抜けを防ぐ。
- スコアは走行距離の半分（整数表示）。接触・事故の加点はない。結果には終了理由、実際の生存時間、走行距離を表示。一時停止・タブ非表示は事故映像中にも有効。
- 物理は固定1/60秒刻み。飛ぶ人形は最大7体、11秒で回収。道路と街区を再利用してシーンの増加を抑える。通常の人形はインスタンシング、街区・車は材質ごとにメッシュを結合。
- サバイバル用ベストスコアのみブラウザのlocalStorageに保存（旧ルールの接触加点スコアとは保存キーを分ける）。使えない場合もプレイできる。
- 読み取り専用の`window.__dashcamDiagnostics()`から状態・衝突数・ラグドール数・有限値チェック・描画呼び出し数を取得できる。`?seed=71823`で配置用乱数の初期値を指定できる。

## 同梱ライブラリ

- Three.js 0.170.0 / BufferGeometryUtils（MIT、`vendor/THREE-LICENSE.txt`）。BufferGeometryUtilsのimport先のみローカルファイルへ変更。
- Rapier 3D compat 0.17.3（Apache-2.0、`vendor/RAPIER-LICENSE.txt`）。WASMを内包するES moduleを利用。

外部CDN・外部画像配信に依存しない。道路・街区・車はコード生成。人物はCC0のMakeHuman由来メッシュと肌テクスチャを同梱し、通常表示と11部位ラグドールで共通の表面を使用する。[人物の出典・加工記録](assets/characters/PROVENANCE.md) を参照。エンジン音・衝突音・クラクションはWeb Audioで合成。セリフ音声の出典と使用範囲は [audio/SOURCES.md](audio/SOURCES.md) を参照。
